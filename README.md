# GXDE Display Manager
GXDE Display Manager (亦称`gxdm`) 派生自SDDM，专为GXDE OS设计，提供开箱即用的登录管理器+greeter体验。

GXDE Display Manager (A.K.A. `gxdm`) is a fork of SDDM that is specially designed for GXDE OS, aiming to provide out-of-box login manager + greeter experience.
